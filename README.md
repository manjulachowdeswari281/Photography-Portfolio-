# Photography Portfolio Website

This is a creative Photography Portfolio Website developed using HTML, CSS, and JavaScript. It showcases beautiful photographs in an attractive and organized layout.

**Technologies Used:**
- HTML
- CSS
- JavaScript

**Features:**
- Attractive dark theme design
- Beautiful photo gallery
- Different photography categories
- Stories section
- User-friendly interface

**Project Objective:**
To create a personal photography portfolio website to showcase photographs and creative photography work.
